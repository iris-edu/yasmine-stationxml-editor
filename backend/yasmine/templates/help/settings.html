Settings

These values are defaults for new inventories and for how Yasmine talks to response libraries. They apply after you click Save.

General

  • GUI Date Format — how dates appear in the interface. The exported StationXML still uses UTC.
  • XML Module, Source, URI — default FDSNStationXML root fields for new documents.
  • XML View Mode — Tree is the inventory tree. Card is a one-level card view of children.
  • NRL Offline — keep a local Nominal Response Library ZIP and refresh it from the catalog updatedsince check.
  • GATITO — URL of the Generic Atomic Library of Tiny Objects used for comment, agency and similar helper lists. Refresh imports it. This is not StationXML schema help.
  • Import a ZIP — load a user library archive from disk.

NRL Online

When enabled, the response wizard can fetch instrument responses from the IRIS/EarthScope NRL web service without a local archive. Test checks the URL. The default host is service.earthscope.org.

Network, Station, Channel

  • Code and counts are wizard defaults for new nodes.
  • Required Fields must be present before Yasmine will save that node. You cannot remove fields that StationXML itself requires.
  • Spread to Channels copies a station coordinate or similar edit down to its channels when you save.

Field-level StationXML meanings are in the builder ? (schema help), not in this Settings panel.
