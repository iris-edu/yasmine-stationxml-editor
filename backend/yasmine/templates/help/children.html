Inventory tree

This pane is the StationXML hierarchy for the current file: Inventory → Network → Station → Channel. Select a node to edit its fields in the parameter list on the right. The ? on that list opens StationXML 1.2 schema help for the selected field.

Add (+)

  • From a user library — insert a saved Network, Station or Channel (and its children) under the current selection.
  • Using a wizard — create the next level step by step, including an instrument response from NRL or AROL.
  • Default — create an empty child with the required StationXML fields only. Fill the rest in the parameter list.

The child type depends on the current selection: Inventory adds a Network, a Network adds a Station, a Station adds a Channel.

Delete (−)

Removes the selected Network, Station or Channel and all of its children. This cannot be undone.

Extract

Copies the selected node into a user library so you can reuse it in other XML files.

Epoch

Filters the tree to nodes that are active on the chosen date. Clear the epoch to show the full inventory again.

File and Builder Mode

  • File → Validate XML reports StationXML 1.2 XSD errors (these block export) and Yasmine/FDSN warnings.
  • File → Export as XML writes StationXML 1.2. Export is blocked if the file fails XSD validation.
  • Builder Mode is this editor. Comparison Mode compares two inventories side by side.
