XML list

This table is the set of StationXML documents stored in Yasmine. Double-click a row, or use the wrench, to open the inventory builder.

Toolbar

  • + — create an empty XML container. Source, Module, URI and Sender become the FDSNStationXML root attributes.
  • − — delete the selected document from Yasmine. This does not delete files on disk.
  • Pencil — rename the container or edit the root Source, Module, URI and Sender values.
  • Wrench — open the Network / Station / Channel editor.
  • Import — load an existing StationXML file. Foreign-namespace extensions are kept.
  • Export — download StationXML 1.2. The download is blocked if XSD validation fails; the error message names the first schema problem.

Use column filters to find a document by name, source, module or date. For field meanings inside a document, open the builder and use the StationXML ? on a parameter.
